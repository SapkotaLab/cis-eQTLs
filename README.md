# cis-eQTLs
Summary statistics from ancestry-specific _cis_-eQTL analyses conducted in childhood cancer survivors of European (EUR) and African (AFR) genetic ancestry from the St. Jude Lifetime Cohort Study (SJLIFE).

The compressed file _cis_-eQTLS.updated.7z contains 18 files with summary statistics for:
  1. Main effect _cis_-eQTLs in EUR survivors (EUR.main_effects.txt)
  2. Survivor-specific (identified in survivors, but absent in GTEx) _cis_-eQTLs in EUR survivors (EUR.survivor_specific.txt)
  3. Survivor-altered (opposite directions of effect in survivors and GTEx) _cis_-eQTLs in EUR survivors (EUR.survivor_altered.txt)
  4. Survivor-exclusive (identified in only one survivor ancestry group) _cis_-eQTLs in EUR survivors (EUR.survivor_exclusive.txt)
  5. Platinum agent-specific _cis_-eQTLs in EUR survivors (EUR.platinum_agent_specific.txt)
  6. Alkylating agent-specific _cis_-eQTLs in EUR survivors (EUR.alkylating_agent_specific.txt)
  7. Abdominal irradiation-specific _cis_-eQTLs in EUR survivors (EUR.abdominal_irradiation_specific.txt)
  8. Chest irradiation-specific _cis_-eQTLs in EUR survivors (EUR.chest_irradiation_specific.txt)
  9. Neck irradiation-specific _cis_-eQTLs in EUR survivors (EUR.neck_irradiation_specific.txt)

  10. Main effect _cis_-eQTLs in AFR (AFR.main_effects.txt)
  11. Survivor-specific (identified in survivors, but absent in GTEx) _cis_-eQTLs in AFR survivors (AFR.survivor_specific.txt)
  12. Survivor-altered (opposite directions of effect in survivors and GTEx) _cis_-eQTLs in AFR survivors (AFR.survivor_altered.txt)
  13. Survivor-exclusive (identified in only one survivor ancestry group) _cis_-eQTLs in AFR survivors (AFR.survivor_exclusive.txt)
  14. Platinum agent-specific _cis_-eQTLs in AFR survivors (AFR.platinum_agent_specific.txt)
  15. Alkylating agent-specific _cis_-eQTLs in AFR survivors (AFR.alkylating_agent_specific.txt)
  16.  Abdominal irradiation-specific _cis_-eQTLs in AFR survivors (AFR.abdominal_irradiation_specific.txt)
  17.  Chest irradiation-specific _cis_-eQTLs in AFR survivors (AFR.chest_irradiation_specific.txt)
  18.  Neck irradiation-specific _cis_-eQTLs in AFR survivors (AFR.neck_irradiation_specific.txt)
