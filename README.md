# cis-eQTLs
Summary statistics from ancestry-specific _cis_-eQTL analyses conducted in childhood cancer survivors of European (EUR) and African (AFR) genetic ancestry from the St. Jude Lifetime Cohort Study (SJLIFE).

The compressed file _cis_-eQTLS_in_survivors.zip contains 12 files with summary statistics for:
  1. Main effect _cis_-eQTLs in EUR (EUR.main_effects.txt)
  2. Platinum agent-specific _cis_-eQTLs in EUR survivors (EUR.platinum_agent_specific.txt)
  3. Alkylating agent-specific _cis_-eQTLs in EUR survivors (EUR.alkylating_agent_specific.txt)
  4. Abdominal irradiation-specific _cis_-eQTLs in EUR survivors (EUR.abdominal_irradiation_specific.txt)
  5. Chest irradiation-specific _cis_-eQTLs in EUR survivors (EUR.chest_irradiation_specific.txt)
  6. Neck irradiation-specific _cis_-eQTLs in EUR survivors (EUR.neck_irradiation_specific.txt)

  7. Main effect _cis_-eQTLs in AFR (AFR.main_effects.txt)
  8. Platinum agent-specific _cis_-eQTLs in AFR survivors (AFR.platinum_agent_specific.txt)
  9. Alkylating agent-specific _cis_-eQTLs in AFR survivors (AFR.alkylating_agent_specific.txt)
  10.  Abdominal irradiation-specific _ci      s_-eQTLs in AFR survivors (AFR.abdominal_irradiation_specific.txt)
  11.  Chest irradiation-specific _cis_-eQTLs in AFR survivors (AFR.chest_irradiation_specific.txt)
  12.  Neck irradiation-specific _cis_-eQTLs in AFR survivors (AFR.neck_irradiation_specific.txt)
